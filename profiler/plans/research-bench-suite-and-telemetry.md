## PipeASIO telemetry (patches 0014, 0015)

Thread: `process_callback(nframes, arg)` in `src/asio.c` is called from `audio_on_process` (upstream `src/audio.c:1546`, the `pw_filter` `.process` handler) as `c->process_cb(c->buffer_size, …)` (audio.c:1600) on PipeWire's data-loop thread, created through Wine's `CreateThread` with an 8 MB stack (has a TEB; `audio_rt_create`, audio.c:123-145; bridge 510-524); thread-name property ignored; no `SetThreadDescription`. Live's bufferSwitch runs on this thread for 64-bit hosts (WoW64 differs → telemetry refused, 0014:502-506). Reports written by `lifecycle_worker` (separate thread).

Phase boundaries (0014:457-494 with upstream asio.c:2550-2600): `entry_to_live` from `telemetry_cycle_begin` (function entry, before `pipeasio_host_call_begin`) to `before_live` (includes possible `sampleRateChanged`, input memcpy, host_time setup); `live_callback` = `swapBuffersWithTimeInfo`/`swapBuffers` (0014:392-413); `live_to_outputs` from `after_live` to `telemetry_cycle_finish` (after the `audio_port_publish_output` loop). Not covered: audio.c's dequeue before and xrun accounting/queueing after. Muted cycle only increments `muted_cycles` (0015:221-227).

Structures (`include/pipeasio_telemetry.h`, 0014:71-183): `sample {uint64_t wall_ns[3]; uint64_t cpu_ns[3]; uint32_t flags;}` (0x1 = time-info); SPSC ring `write_seq`, `read_seq`, `dropped`, `slots[8192]`; state `{ring; _Atomic muted_cycles; int output_fd}` (0015:96-97). Clocks `CLOCK_MONOTONIC` + `CLOCK_THREAD_CPUTIME_ID` (0014:252-257). **Deltas only**: no absolute timestamps, nframes, rate, quantum or deadline.

Non-blocking output (0015): `telemetry_open_report_fd` (106-116) reopens stderr `O_NONBLOCK` when it is a FIFO/char device; `telemetry_log` (121-138) one `write()` into a 1 KiB buffer, drops on full pipe; emitted only when `WaitForSingleObject(work_event, 1000)` times out (0014:434-447) and once at `destroy_driver_resources`. `PIPEASIO_TELEMETRY` read in `configure_driver` (from ASIO `Init`, asio.c:1260) via `pipeasio_env_bool`. Log lines: `[pipeasio telemetry] enabled for 64-bit host; capacity=8192, interval_ms=1000`, `[pipeasio telemetry] cycles=<published+muted> time_info=N legacy=N muted=N dropped=N`, `[pipeasio telemetry] monotonic_wall_ns phase=entry_to_live p50=.. p95=.. p99=.. max=..` (×3 phases, then `thread_cpu_ns` ×3). No timestamps; land in `raw/launcher.log` → `raw/log-N-window.txt`; never parsed (only `WARN: xrun: missed the cycle deadline` matches `XRUN_RE`).

Available at the callback: `nframes`, `This->host_sample_rate`, `audio_get_time_nsec()`; in audio.c `clock.duration`, `clock.rate.denom`, `clock.position`, `clock.id`, `clock.next_nsec`; `xrun_count` from position gaps (1603-1630); `cycle_count` only with `PIPEASIO_DEBUG`. Shipped: `lib/wine/x86_64-unix/pipeasio64.dll.so` (`pipeasio.dll.so` symlink), Release, `strip --strip-unneeded`; `process_callback` is `static inline`.
