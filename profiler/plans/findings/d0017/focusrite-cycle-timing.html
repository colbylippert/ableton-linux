PipeWire · Focusrite Scarlett 2i4 · 64 frames at 48 kHz

Focusrite cycle timing

Each PipeWire cycle hands Live one 64-frame buffer, 1.333 ms of audio, and Live must finish before the next cycle starts. The Focusrite's USB driver reports its progress only every 0.5 ms. The two traces below show the same 8 ms before and after switching the card from interrupt-driven to timer-driven scheduling, drawn to the same scale.

The first six rows come from one 30 s bench run per mode on the Inbuilts Set with 2 audio workers, recorded with PipeASIO's probes from Live's first buffer (D0016, D0017). The full-pass rows come from three runs per mode, each from a fresh boot, playing Inbuilts, Max4Live and VSTs for 120 s each (D0014, D0017), all on 2026-10-20. Three errors against none is not yet significant on its own; a load ramp, where errors are frequent, is the stronger test. The switch is a WirePlumber rule on the Focusrite's pro-audio nodes, api.alsa.disable-tsched = false with api.alsa.headroom = 32, which PipeWire raised to 64 while streaming.
